# nagara

エンジニアが「ながら」で学べる、短い技術動画のプラットフォーム。

## コンセプト

- **短い**: 1 本 5〜10 分、1 テーマ（例:「5分で理解するSRE」）
- **耳だけでも分かる**: 画面を閉じても聞き続けられる「ながら再生」
- **AI で作った動画も歓迎**

見る人は、通勤や家事の合間に技術をざっくり掴みたいエンジニア。投稿する人は、知っていることを記事より手軽に共有したいエンジニア。

## できること（MVP）

- 動画（MP4 / WebM）の投稿
- 一覧とキーワード検索
- 視聴（シーク、再生速度 1〜2 倍）
- ながら再生: 同じ動画を音声だけで再生する。スマホで画面を閉じても止まらず、ロック画面にタイトルが出る

## 動かす

Go 1.24 以上が必要です。外部ライブラリは使っていません。

```sh
go run ./cmd/nagara
```

http://localhost:8080 を開きます。投稿した動画は `./data` に保存されます。

```sh
go run ./cmd/nagara -addr localhost:3000 -data /path/to/data  # ポートと保存先を変える
go test ./...                                                 # テスト
```

## 構成

```
cmd/nagara/          起動と組み立て
internal/video/      動画そのもの（入力の検証、検索）。何にも依存しない
internal/filestore/  動画をディレクトリに保存する
internal/web/        画面と HTTP。保存先は Library インターフェース越しに使う
```

依存の向きは `web → video ← filestore`。`web` と `filestore` はお互いを知らず、`main` がつなぐ。

## まだやらないこと

ログイン、コメント、サムネイル、動画の変換（エンコード）。必要になったら足します。
今はローカルで動かす前提のため、認証も CSRF 対策もありません。公開する前に入れます。
